# MCP Khaihoanderma v1.0.0

Phiên bản khởi tạo chính thức với định danh mới **MCP Khaihoanderma**.

## Tính năng và cập nhật

- Đổi tên ứng dụng và nhận diện chính thức: **MCP Khaihoanderma**.
- Hỗ trợ đầy đủ bộ công cụ:
  - Tự động viết nội dung và chuẩn bị bài đăng cho Website Khải Hoàn Derma và Fanpage Facebook.
  - Tích hợp điều khiển Chrome Debug tạo ảnh ChatGPT chất lượng cao, tự động lưu ảnh 1–4 chuẩn xác.
  - Đồng bộ sản phẩm Notion và liên kết lưu trữ ảnh Google Drive.
- Kiến trúc bảo mật cấu hình: API key lưu cục bộ an toàn, tự động mã hóa.
- Bộ cài đặt đa nền tảng cho Windows x64 và macOS Universal (Apple Silicon & Intel).
